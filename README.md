# Sigma plugins

Custom [Sigma Computing](https://sigmacomputing.com) plugins, served via GitHub Pages.

## kobalt-royalty-pipeline

A royalty pipeline flow for music publishing: what was **earned** in a period,
how much of it a statement has actually been **collected** for, and how much of
that has **settled** to the writer versus sitting in a pending payment run or
held in suspense.

Bind it to any element exposing six numeric columns (net payable, statement
received, awaiting statement, paid, pending, in suspense). It renders a synthetic
example until an element is bound, so it never looks broken in the editor.

URL: `https://gabrieljonessigmacomputing.github.io/sigma-plugins/kobalt-royalty-pipeline/index.html`
